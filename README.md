# -ewi92.github.io

A simple public photography portfolio website for GitHub Pages.

## Publish your site

This repository is already named like a user Pages site (`<username>.github.io`), so GitHub can serve the `index.html` file at the repository root as a public website.

## Customize

- Edit `/home/runner/work/-ewi92.github.io/-ewi92.github.io/index.html`
- Replace the sample gallery image URLs with your own photos
- Update the About and Contact sections with your details
