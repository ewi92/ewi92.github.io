# -ewi92.github.io

A simple public photography portfolio website for GitHub Pages.

## Publish your site

This repository is already named like a user Pages site (`<username>.github.io`). In this project, the published Pages source is the `/docs` directory, so update `docs/index.html` for the live homepage.

## Customize

- Edit `/home/runner/work/ewi92.github.io/ewi92.github.io/docs/index.html`
- Replace the sample gallery image URLs with your own photos
- Update the About and Contact sections with your details
